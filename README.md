# ÌLÚ Supply Co.

Concept homepage for a Lagos streetwear label: photo hero slider, overlay nav, AI stylist panel, categories, new arrivals, Harmattan edit, bestsellers slider, drop countdown, brand story, Instagram grid, newsletter and footer.

Static site — plain HTML, CSS and JavaScript, no build step.

- `index.html` — the page
- `images/` — hero, product and section images (photography via [Unsplash](https://unsplash.com))
- `vercel.json` — clean URLs and long cache for images

## Run locally

```bash
npx serve .
```

## Deploy

Import the repo on Vercel with the **Other** framework preset. No build command, output directory is the repo root.
